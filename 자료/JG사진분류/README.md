# JG사진분류

- 종류: 프로그램
- 버전: 1.3.0
- 올린 날짜: 2026-10-27

## 무엇인가요

본 프로그램은 태안군청 현장직의 사진 분류 및 관리를 위하여 제작된 프로그램입니다.
본 프로그램 및 관련 자료는 태안군청 내부 사용 전용이며,
태안군청 이외의 기관·개인에게 공유·전달·배포하는 것을 절대 금지합니다.
프로그램 관련 문의는 김자균에게 문의해 주시기 바랍니다.
