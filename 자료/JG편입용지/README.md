- 종류: 프로그램
- 버전: -
- 올린 날짜: 2026-10-27

## 무엇인가요

본 프로그램은 편입예상필지 조서와 편입용지도를 자동으로 만들어 주는 Windows 프로그램입니다.

본 프로그램 및 관련 자료는 태안군청 내부 사용 전용이며,
태안군청 이외의 기관·개인에게 공유·전달·배포하는 것을 절대 금지합니다.
프로그램 관련 문의는 김자균에게 문의해 주시기 바랍니다.

(편입예상필지 조서는 참고용으로만 사용해주시기 바랍니다)
